# 🏹 神射巔峰：雙人弓箭對決 (Archery Masters: 2-Player Showdown)

高品質雙人對戰射箭競技網頁遊戲，具備真實拋物線物理彈道、動態風向風速系統、擊中判定、即時靶心特寫放大鏡頭與純程式合成立體音效！

---

## 🌟 遊戲模式介紹

### 1. 🎯 標靶競分賽 (Target Championship)
- **經典競技模式**：兩位神射手輪流上場，每局射擊 3 支箭（可自由設定 1 局快節奏、3 局決勝或 5 局大賽）。
- **專業 10 環標靶計分**：
  - **黃心 X-Ring (中心最內圈)**：10 分 + 特級神射特效
  - **黃心 10 環**：10 分 + 勝利鐘鳴
  - **紅心區**：8 分
  - **藍圈區**：6 分
  - **黑圈區**：4 分
  - **白圈邊緣**：2 分
- **動態移動靶**：可於設定中開啟「上下擺動靶」，考驗預判時機！
- **靶心近景特寫鏡頭 (PIP Mini-Cam)**：右下角圓形鏡頭即時顯示每一支箭在標靶上的落點座標與色彩針標。

### 2. ⚔️ 生死決鬥場 (Bow Masters Duel)
- **雙人血量淘汰對決**：
  - 玩家 1（🔥 烈焰遊俠）與玩家 2（❄️ 霜風守望）分別站在懸崖兩側互射！
- **部位受傷判定**：
  - **💥 爆頭暴擊 (HEADSHOT)**：造成 **45 HP** 巨量傷害 + 金屬重擊音效與震屏
  - **身體軀幹**：造成 **25 HP** 傷害
  - **腿部擦傷**：造成 **15 HP** 傷害
- 一方血量歸零時，勝者將獲頒榮耀獎盃並觸發滿屏慶祝紙花！

### 3. 🏹 單人打靶訓練 (Solo Practice)
- 無限箭矢，放鬆心情練習拋物線手感、風力修正與累積最高連擊 (Streak Combo)！

## 🎮 操作方式說明

### 滑鼠 / 觸控操作
1. **拉弓蓄力**：在輪到的弓箭手身上**按住滑鼠左鍵（或手指觸控）並向後拉曳**。
2. **調整角度**：向後與上下移動可直覺微調仰角與拉滿百分比。
3. **發射飛箭**：放開滑鼠（或手指），箭矢便會破空射出！

### 鍵盤輔助操作
- `↑` / `W`：提高射擊仰角
- `↓` / `S`：降低射擊仰角
- `空白鍵 (Space)`：長按蓄力，放開發射

## 💨 競技戰術與技巧
- **風向儀**：畫面正上方的風向羅盤會顯示即時風向箭頭與風速數值（例：`2.5 m/s ➔` 或 `⬅ 4.8 m/s`）。
  - **順風**：箭矢水平速度加速、射程更遠，建議適度降低仰角或蓄力。
  - **逆風**：箭矢受到強大阻力，需要拉高仰角並拉滿蓄力！
- **初段彈道輔助**：可於選單設定開啟或關閉軌跡預覽點，高手可切換「硬派真實」考驗真正神射功力。

## 🚀 如何啟動遊玩

1. **直接開啟**：用任何現代瀏覽器（Chrome、Edge、Safari、Firefox）直接雙擊開啟 `index.html`。
2. **本地伺服器**：
   ```bash
   python -m http.server 8080
   ```
   並在瀏覽器輸入：`http://localhost:8080` 即可暢快遊玩！
